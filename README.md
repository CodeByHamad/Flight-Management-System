# Flight Management System

## Overview

The Flight Management System is a console-based C++ application designed to manage airline flight operations. The system allows administrators to add, search, view, sort, and delete flights, as well as manage ticket bookings and cancellations. All flight and booking data is stored using file handling, ensuring persistence between program executions.

## Features

### Admin Authentication

* Secure admin login using password verification.
* Prevents unauthorized access to the management system.

### Flight Management

* Add new flights.
* View all available flights.
* Search flights by flight number.
* Delete flights from the system.

### Ticket Management

* Book tickets for available flights.
* Cancel booked tickets.
* Automatically update seat availability.

### Revenue Management

* Generate revenue reports.
* Track income generated from ticket bookings.

### Sorting Functionality

* Sort flights by ticket price.
* Makes flight comparison easier for administrators.

### File Handling

* Stores flight records permanently in files.
* Preserves data after program termination.

## Flight Information

Each flight record contains:

* Flight Number
* Origin
* Destination
* Departure Time
* Economy Class Seats
* Economy Ticket Price
* Business Class Seats
* Business Ticket Price
* First Class Seats
* First Class Ticket Price
